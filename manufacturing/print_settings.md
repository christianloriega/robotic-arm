# Manufacturing & Print Settings

This document records the manufacturing parameters used for major
3D-printed components of the robotic arm.

---

## Link 1 — Optimized

### Print Settings

- Material: PETG
- Layer Height: 0.20 mm
- Wall Loops: 6
- Infill: 30%
- Infill Pattern: Gyroid
- Top Layers: 6
- Bottom Layers: 6
- Print Orientation: Broad face on build plate

### Design Features

- Ribbed internal structure for improved stiffness-to-mass ratio
- Integrated wire-routing features
- Servo-horn mounting interface for horn actuator
- Structural fillets at rib intersections

### Design Metrics

- Baseline CAD Mass: 157.1 g
- Optimized CAD Mass: 128.9 g + wiring router weight
- CAD Mass Reduction: 17.9%
